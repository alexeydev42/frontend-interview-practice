# Async User Summary

Практическое упражнение по асинхронному JavaScript: `Promise.all()`, `async/await`, обработка ошибок и тестирование.

## Описание

Функция `loadUserSummary(userId)` получает данные пользователя и список его задач, подсчитывает количество выполненных задач и возвращает объект с именем пользователя и количеством завершённых задач.

Для получения данных используются две функции, имитирующие запросы к API:

- `getUser()` возвращает промис с данными пользователя через 300 мс.
- `getTasks()` возвращает промис со списком задач через 500 мс. Для неподдерживаемого ID промис отклоняется с ошибкой `Tasks not found`.

## Почему Promise.all()

Оба запроса зависят только от переданного `userId` и не требуют результатов друг друга. Поэтому их можно выполнять одновременно через `Promise.all()`, не дожидаясь последовательного завершения каждого запроса.

Если один из промисов отклоняется, общий промис `Promise.all()` тоже отклоняется. Ошибка перехватывается через `try/catch`, её сообщение выводится в консоль, а функция возвращает `null`.

При этом отклонение `Promise.all()` не отменяет остальные запущенные операции.

## Тестирование

Тесты написаны с использованием встроенных модулей Node.js `node:test` и `node:assert/strict`.

Проверяются два сценария:

- Успешное получение пользователя и правильный подсчёт выполненных задач.
- Ошибка при получении задач: функция возвращает `null`, а `console.error()` вызывается с ожидаемым сообщением.

Для проверки вызова `console.error()` используется `mock`.

Дополнительно тесты проверялись намеренным внесением ошибок в код, чтобы убедиться, что они способны обнаруживать неверный результат.
