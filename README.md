# Frontend Interview Practice

A collection of practical exercises for preparing for technical interviews for a Junior Frontend Developer position.

This repository contains selected exercises focused on JavaScript, TypeScript, and React. The goal is to strengthen my understanding of core concepts, practice problem-solving, and improve my ability to explain technical decisions.

Each exercise focuses on a specific concept or problem. Some include automated tests and short explanations of key takeaways.

## Topics

- **JavaScript** — asynchronous programming, data manipulation, and core language concepts.
- **TypeScript** — type safety and practical use of the type system.
- **React** — components, hooks, and state management.

## Running Tests

The exercises use Node.js and its built-in test runner, without additional testing dependencies.

Run all tests from the project root:

```bash
npm test
```

## About This Repository

This is a personal learning and interview preparation repository, not a production application. It contains selected exercises that helped me understand, practice, or reinforce important frontend development concepts.
